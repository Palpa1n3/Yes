# Notes for Claude

- The app is ARC, a Windows desktop assistant (Electron + React + TypeScript). The user may call the assistant by the name they set in Settings. See README.md for features and architecture.
- Before committing, run `npm run typecheck`, `npm run lint` and `npm test`.

## Roadmap

`ROADMAP.md` is the ordered queue of features to build.

- When you finish a roadmap item, move it to **Done** in `ROADMAP.md` (with a one-line summary) and update the README for the new feature.
- At the end of any finished feature, tell the user which item is next in **Up next** and give a one-line pitch for it, so they can say "go" or pick another.
- If you think of a new feature while working, add it under **Ideas** rather than building it.
